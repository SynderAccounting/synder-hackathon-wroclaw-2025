The application automatically retrieves order data from Shopify and Square via API and will later be expanded to support other platforms such as Amazon and Etsy. It synchronizes orders, merges products with identical SKUs, and calculates the total revenue and number of units sold. Cancelled orders are excluded from reports. Results are presented in interactive tables and charts. The application also provides the ability to analyze the reasons for product returns.

### Business Problems It Solves
- Automation of sold product calculations.
- Reduction of manual operations between multiple platforms.
- Providing up-to-date sales analytics.

### Main Scenarios (User Flow)
- The user authorizes through Shopify and Square.
- The application retrieves the list of orders from both platforms via API.
- The data is combined and processed by SKU, date, and quantity.
- The application displays a report showing the number of sold items and total revenue.
